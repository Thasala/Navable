# Navable Privacy Policy

Effective date: May 26, 2026

Navable is a Chrome extension for accessible webpage navigation using voice or typed commands, page structure scanning, optional AI assistance, and screen-reader-friendly feedback.

## Data Navable Processes

Navable processes webpage structure needed for its user-facing features, including page titles, URLs, headings, links, buttons, form labels, landmarks, focused element labels, and short visible text excerpts.

Navable processes user commands when a user types a command or starts voice input. Voice input is transcribed by the browser when available. If the user enables AI features, short voice clips, command text, and minimized page context may be sent to the Navable backend for transcription, summaries, answers, translation, or site resolution.

Navable stores extension preferences in Chrome storage, such as language, output mode, AI feature preference, continuous listening preference, and privacy settings. The Navable start page may store the user's chosen display name locally in Chrome storage.

## Sensitive Data Protections

Navable excludes password fields and payment-card fields from page summaries and backend page-context snapshots where supported. The extension does not intentionally collect passwords, payment card numbers, authentication tokens, or financial account numbers.

Navable can be configured to skip sensitive sites. Form field protection is always enabled.

## How Data Is Used

Navable uses data only to provide or improve its single purpose: accessible webpage navigation and related voice, typed-command, summary, and answer features.

Navable does not sell user data.

Navable does not use or transfer user data for advertising, retargeting, creditworthiness, lending, or unrelated purposes.

Navable's use and transfer of information received from Chrome APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

## Backend And AI Services

When AI features are enabled, Navable may send the minimum data needed for the requested feature to `https://navable.onrender.com`, the Navable backend API. The backend may use OpenAI API services to provide transcription, summaries, answers, translations, or related AI responses.

Backend responses are treated as data only. Browser navigation and page automation decisions are handled by logic packaged inside the extension.

## Data Sharing

Navable shares user data only when needed to provide the requested feature:

- Navable backend API: receives minimized command, voice, and page-context data for enabled AI features.
- OpenAI API services: may process the same minimized data when needed for AI transcription, summaries, answers, translations, or site resolution.

Navable does not share user data with advertising platforms, data brokers, or information resellers.

## Security

Navable transmits backend requests over HTTPS. Navable does not load or execute remotely hosted JavaScript or WebAssembly. All extension code is packaged with the extension.

## Human Access

Navable does not allow humans to read user data except when the user gives explicit consent for support, when required for security or abuse investigation, when required by law, or when data is aggregated and anonymized for internal operations.
